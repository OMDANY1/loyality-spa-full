# Coding Standards

## General

Write clean code.

Readable before clever.

No duplicated code.

Favor composition over inheritance.

---

## Components

Each component should have a single responsibility.

Components must be reusable.

Avoid deeply nested components.

---

## Naming

PascalCase for Components

camelCase for variables

UPPER_CASE for constants

Clear file names.

---

## Folder Structure

/components

/features

/lib

/hooks

/types

/utils

/public

/app

/styles

---

## Styling

Tailwind only.

Avoid inline styles.

Avoid unnecessary custom CSS.

Use utility classes consistently.

---

## Performance

Lazy load heavy components.

Optimize images.

Dynamic import when appropriate.

Avoid unnecessary re-renders.

---

## Responsive

Desktop First

Tablet

Mobile

Test every breakpoint.

---

## Accessibility

Semantic HTML.

Keyboard Navigation.

Proper Labels.

Focus States.

Alt Text.

ARIA only when required.

---

## Comments

Explain WHY.

Never explain obvious code.
