# UI Design System

## Design Philosophy

The UI should disappear behind the experience.

Users should never feel they are interacting with software.

Every interface element should communicate calmness, elegance and confidence.

The design system should prioritize breathing room over information density.

---

# Design Principles

Less but Better

Luxury through simplicity

Function follows emotion

Consistency without repetition

Natural hierarchy

Visual rhythm

Accessibility by default

# Buttons

Primary

Solid warm dark color

Rounded

Large padding

Elegant hover animation

Secondary

Outlined

Transparent background

Ghost

Text only

Icon Button

---

# Cards

Cards should never dominate the page.

Cards should support content.

Use soft shadows only.

Avoid heavy borders.

---

# Forms

Minimal labels

Large inputs

Rounded corners

Comfortable spacing

Clear validation

Elegant focus states

---

# Icons

Thin

Minimal

Rounded

Consistent stroke width

Never use colorful icons.

---

# Images

Large

High quality

Natural lighting

Rounded corners

Editorial crops

Avoid artificial compositions.

---

# Shadows

Very soft.

Multiple layered shadows.

No harsh shadows.

---

# Borders

Only when necessary.

Prefer contrast using spacing.

---

# Dividers

Use generous whitespace before using borders.
