# Performance Requirements

## Core Web Vitals

LCP < 2.5s

CLS < 0.1

INP < 200ms

---

## Images

Use Next/Image.

Lazy load below the fold.

Use AVIF/WebP.

Responsive sizes.

Blur placeholders.

---

## Fonts

Self-host fonts.

Preload primary font.

Limit font weights.

---

## JavaScript

Code Splitting.

Dynamic Imports.

Tree Shaking.

Avoid heavy dependencies.

---

## Animations

GPU accelerated.

Avoid layout thrashing.

Use transform and opacity.

Throttle expensive listeners.

---

## Caching

Static pages where possible.

ISR for dynamic content.

CDN caching.
